# Статичний веб-блог «Мої 3 найкращі міста світу»

Проєкт розроблено в межах Лабораторної роботи №1 з дисципліни **WEB-програмування**.

## Опис проєкту
Веб-сайт являє собою багатосторінковий статичний блог із семантичною HTML-розміткою. Сайт містить інформацію про 3 обрані міста (Київ, Львів, Токіо), навігацію між сторінками та HTML-форму для зворотного зв'язку.

## Структура проєкту
* `index.html` — Головна сторінка блогу.
* `city-kyiv.html` — Сторінка про Київ.
* `city-lviv.html` — Сторінка про Львів.
* `city-tokyo.html` — Сторінка про Токіо.
* `form.html` — Форма «Запропонувати місто».
* `images/` — Каталог із графічними ресурсами (`kyiv.jpg`, `lviv.jpg`, `tokyo.jpg`).
* `README.md` — Опис проєкту.

## Використані технології
* HTML5 (семантична розмітка)
* Git & GitHub (контроль версій)
* GitHub Pages (деплой сайту)
